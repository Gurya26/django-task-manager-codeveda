# 🚀 Django Task Manager

A modern full-stack Django Task Manager web application built during my internship journey with Codveda Technology.

## 🌐 Live Demo

https://django-task-manager-codeveda-2.onrender.com/

---

## 📌 Features

✅ User Authentication (Signup/Login/Logout)

✅ Password Reset System

✅ Add Tasks

✅ Edit Tasks

✅ Delete Tasks

✅ Mark Tasks as Completed

✅ Search Tasks

✅ Task Priorities (High / Medium / Low)

✅ Due Dates

✅ User-Specific Tasks

✅ Responsive Modern UI

✅ Django Admin Panel
